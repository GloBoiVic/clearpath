# distraction-free source audit

Audited on 2026-11-17 at commit [`7bf0c4718941a716f8be68a79736a9c4f8543a3a`](https://github.com/pratikkuikel/distraction-free/tree/7bf0c4718941a716f8be68a79736a9c4f8543a3a). Scope: macOS daemon, DNS helpers, configuration, lists, installers, diagnostics and package manifest. Android, release binaries and full menu-bar behavior were not security-audited. No upstream installer or daemon was executed. Only the reviewed DNSMessage and DomainTrie helpers were compiled into an isolated reproduction program.

## Reuse recommendation

**Do not fork the daemon/installer as the foundation.** Its Swift domain trie is simple and its local policy direction is useful, but the resolver protocol, failure handling and system deployment need substantial replacement. An independent small core is easier to reason about than removing schedules, gamification, fake-disable behavior and unrelated category blocking. The upstream application is [MIT licensed](https://github.com/pratikkuikel/distraction-free/blob/7bf0c4718941a716f8be68a79736a9c4f8543a3a/LICENSE); reuse is permitted with notice, but no upstream application source is included in Clearpath. Blocklist data has separate licensing.

Good ideas to retain: boundary-aware suffix matching; local decisions; dynamically resolving provider SafeSearch targets; category separation; a genuinely unprivileged UI. Do not copy claims of all-app protection without accounting for encrypted DNS and tunnels.

The trie passed a basic subdomain/near-match reproduction. This is useful correctness evidence for that helper, not a complete validation of the application. The package defines executable targets without an automated test target; the README also describes a lack of automated coverage.

## Reproduce the packet findings safely

Download source only to a scratch directory, pin the commit, and inspect the two helpers before compiling. Never invoke `install.sh`, `install-release.sh`, the package postinstall, `run-daemon.sh`, or `update-blocklist.sh` on the host.

```sh
git clone https://github.com/pratikkuikel/distraction-free.git /tmp/distraction-free-source
git -C /tmp/distraction-free-source checkout 7bf0c4718941a716f8be68a79736a9c4f8543a3a
.venv/bin/python scripts/audit_upstream.py /tmp/distraction-free-source
```

The harness compiles only DNSMessage.swift and DomainTrie.swift with its own main in a temporary directory. It neither starts network listeners nor activates system services. It asserts: AAAA answer type is A, synthesized response retains AD, both EDNS replies contain extra trailing bytes, subdomain matches true and near-match false. Temporary build products are removed automatically. These checks passed on the audit machine.
